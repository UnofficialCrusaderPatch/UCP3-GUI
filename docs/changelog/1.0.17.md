# GUI 1.0.17

Preview notes for the next release. Not released yet.

## Find and manage extensions more easily

- Search names and descriptions in your chosen GUI language, using words you remember. Partial names and small typing mistakes are supported.
- Search below the available list, including translated tag names supplied by creators. Turn on whole-word matching for more precise results.
- Use one compact filter menu for tags and hiding modules. Match any selected tag by default, or switch to matching all of them with one click.
- Browse related extensions in expandable families. Use the left arrow to show other members while keeping the row clear and readable. Creators choose which member is the main option.
- See what an extension needs and which active extensions depend on it, with expandable lists in its details.
- Switch Creator mode directly from Content as well as Customisations.
- Open your extensions folder or find an installed extension directly from the Content tab.

## Smoother setup and customization

- New installations get compatible updates for their included extensions automatically. Existing setups keep their current choices.
- Updated extensions can offer richer settings menus, including texture previews. Saving and reopening these menus keeps your choices more reliably.
- Supported in-game extensions can follow the language selected in the launcher.
- GUI update notices no longer keep reappearing when you switch tabs.
- Reset buttons stay visible while you move the pointer onto them.
- Search, filters and Store details fit more comfortably in smaller windows, with clearer controls and keyboard support.

## Platform updates

- Improved Linux installation requirements and download guidance.
- Preview builds are available for both Apple Silicon and Intel Macs.

Families, richer menus and in-game translations appear in extensions that support them. Existing extensions and saved setups continue to work; this preview does not migrate packages.

At larger interface sizes, maximize the window or use the outer scrollbars to reach content that does not fit.
