The Content tab has a folder button beside the filter and install controls. It
opens the selected installation's `ucp` directory, which contains `modules` and
`plugins`. It is unavailable until that directory exists.

Installed extension rows also have a folder button. Windows selects the installed
directory or archive in Explorer; Linux opens its containing directory (as the
tooltip states). Active plugins in Creator mode keep their direct folder-opening
action. Missing items, stale installations and inaccessible paths report an error.
These actions never open an archive with its file association or create folders.

English and German labels are supplied. Other languages use the launcher's
existing English fallback for missing keys; these are not completed translations.
