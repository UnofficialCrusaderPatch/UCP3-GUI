# GUI 1.0.17

- New installations start with UCP3 Basics + Fixes from the Store, or with the previous defaults (UCP2 legacy defaults and the graphics API replacer) when no compatible version can be installed.

- New installations update the included extensions to the newest compatible Store versions, and keep the bundled versions when the Store is unavailable.
- First-use defaults pick the newest installed version by version number.

The Content tab can open the selected installation's `ucp` folder and reveal any
installed extension, including inactive modules/plugins. Windows selects the item;
Linux opens its containing folder. Creator plugins retain direct folder opening.
Missing/stale paths report an error. Labels are English/German with English fallback.

- When an extension requires a different value for one of your settings, the launcher changes the saved setting and shows each change as old → new, on load and before activating or upgrading. Customisations always show the value the game uses.
- If a saved setup can't be loaded, Save before launch leaves the file alone.

- Keep the reset bin visible while moving the pointer from a setting onto it, so it can be clicked reliably.

- Before you deactivate, uninstall or upgrade away a module that saved games depend on, the launcher names it and asks first. Module creators declare this with `save-state` in `definition.yml` ([docs/save-state.md](../../save-state.md)).

- Search extensions by name, description and translated tags in your GUI language, and filter by tags.
- Choose one configuration from an extension family, such as Bare or Applied. A switch shows what changes first, and a saved setup with two choices from one family asks which one to keep.

- Uninstall extensions from the Store even while they are active: the review lists dependent packages that go too, says which removed versions the Store can reinstall, and can also remove dependencies nothing else uses.

## Launch

Enable Allow Multiple Games to start another game instance with framework 3.0.8.
